# EnjoyMagnets Storefront (Next.js 14 - App Router)

Bootstrap minimale pronto per l'avvio in produzione.

## Requisiti
- Node 20 (vedi .nvmrc)
- PNPM/NPM/Yarn a scelta

## Setup
\\\ash
npm install
npm run dev # avvia su http://localhost:3001
\\\

## Note
- Tailwind configurato (app/globals.css include le direttive).
- i18n: cartella \/i18n\ con JSON placeholder (non collegato a runtime).
- \
ext.config.mjs\ abilitato per immagini remote da CDN Bunny/Origin.
